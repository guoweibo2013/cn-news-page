# 编辑与评分规则

## 来源分层

| 层级 | 示例 | 用途 |
|---|---|---|
| 官方直源 | 中国政府网、新华网 | 政策、通报和重大时政信息的优先来源 |
| 新闻源 | 中国新闻网、IT之家等 | 形成事件候选，提供标题、摘要、发布时间和原文链接 |
| 热榜线索 | 百度热搜、B站热门 | 发现公众注意力，不得作为事实依据 |
| 外部补证 | 官方通报、其他独立媒体 | 在用户要求核实时补充 |

同一出版集团的不同频道只算一个独立新闻来源。三家媒体转载同一稿件也不等于三个独立来源。

## 事件排序

脚本默认使用以下信号，满分100：

- 新鲜度约30分，越接近当前时间越高。
- 来源等级约27分，政府与中央媒体直源高于普通新闻源和热榜。
- 独立来源印证约18分，同一出版集团只计一次。
- 热榜关注度约12分，只作为线索信号。
- 事件影响关键词约8分，包括发布、政策、预警、事故、通报、回应等。
- 查询相关性约5分，仅在用户指定主题时产生明显差异。

具体权重以实现为准。评分是检索优先级，不是事实真实性的概率。

## 事件合并

标题字符片段相似度、最长公共片段和相同链接用于合并转载。合并时必须保留：

- 最早出现的新闻时间。
- 最近更新时间。
- 不同新闻来源的原文链接。
- 与事件匹配的热榜词，但不将其计入独立新闻来源数。

不要为了减少条目强行合并只有单个宽泛词相同的事件。

每个事件需尽量提供“为什么重要”、官方来源覆盖、新闻时间线、不同来源链接以及待核实状态。2026-11-25 起，独立页面使用跨运行缓存标记“新事件”和“刚刚更新”；没有缓存时，现有事件会显示为新事件。

## 扩展来源

运行 `python3 scripts/news_pulse.py --help` 查看参数。临时增加RSS：

```bash
python3 scripts/news_pulse.py --rss "中国新闻网财经=https://www.chinanews.com.cn/rss/finance.xml"
```

新增默认来源时，应验证：

1. 返回RSS或Atom，而不是验证码或HTML登录页。
2. 发布时间正确且持续更新。
3. 链接可公开访问。
4. 使用频率符合来源条款。

优先选择官方RSS、开放API、公开榜单或已获授权的数据接口。不要绕过验证码、访问控制或付费墙。
